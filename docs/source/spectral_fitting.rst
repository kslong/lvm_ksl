Spectral Fitting
=================

Tools for turning an extracted or reduced LVM spectrum into physical
line and continuum measurements, plus the overview plots used to
inspect a spectrum before or after fitting it. There are two
independent routes to line measurements -- fast local ``lmfit``-based
Gaussian fits, or the full LVM-DAP stellar-population + emission-line
pipeline -- and a separate family of tools for visual overview plots
spanning the full wavelength range.
